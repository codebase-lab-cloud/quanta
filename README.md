# Quanta — Private Portfolio Tracker

## Purpose
Quanta is a secure, private portfolio tracking and financial monitoring web application that keeps your holdings and net worth data synchronized directly via GitHub.

## Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript, CSS3
- **Data & Sync**: GitHub Contents API (authenticated zero-knowledge fetching)
- **Architecture**: Progressive Web App (PWA) with Service Worker offline caching and dual dark/light themes

## About
Quanta operates with a zero-server privacy architecture: no personal portfolio data or credentials are stored on central servers. The public client acts as a secure shell that connects directly to the user's private repository for personal data management.
